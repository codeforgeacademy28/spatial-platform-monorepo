# Blueprint to Spatial 3D Workflow

1. Upload blueprint — JPG/PNG floor plan becomes the 2D tracing background.
2. Calibrate scale — enter a known real-world distance and click Apply.
3. Trace walls in 2D — press and drag inside the plan; release to create a wall.
4. Validate rooms — connect wall endpoints into closed loops; review room names and areas.
5. Inspect 3D — every wall is extruded automatically; orbit, zoom and pan the model.
6. Spatial / AR — enter AR after validating the 3D geometry; save/share/version the project.
