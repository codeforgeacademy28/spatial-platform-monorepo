# Birthday Gallery Experience

This feature branch adds a scene/presentation layer without replacing canonical blueprint geometry.

### Included
- Per-wall colour/material metadata.
- Real wall openings for doors/windows.
- Wall-anchored artwork and gallery spotlights.
- Optional ceiling.
- Full-screen Birthday Gallery presentation mode.
- Project data remains JSON-compatible and additive.

### Product direction
Blueprint → rooms → decorated scene → guided walkthrough → final reveal.

### Next polish
Draggable artwork handles, persistent R2 asset keys with signed URL refresh, explicit experience checkpoints, audio, animated doors, and richer 3D decorations.
