# Spatial Walkthrough Smoke-Test Checklist

Run this checklist on the latest deployed build after the engineering gate passes. Record browser, device, commit SHA, and each result. Do not mark AR as verified from desktop emulation alone.

## Desktop walkthrough

- [ ] Open Spatial View and confirm the building is centered and not unexpectedly rotated or offset.
- [ ] Select **First-Person Walk**; click the canvas to lock the pointer.
- [ ] Move with W/A/S/D or arrow keys; confirm diagonal speed is not faster than straight movement.
- [ ] Move the mouse; confirm camera yaw/pitch responds and pitch cannot flip upside down.
- [ ] Hold Shift to sprint; press Space to jump; release focus/press Escape to exit pointer lock.
- [ ] Walk toward each wall from both sides; confirm movement is blocked, and movement along the wall remains possible.
- [ ] Start near a wall and move away; confirm the player is not trapped.
- [ ] Toggle collision off/on and confirm the HUD reflects the actual state.
- [ ] Exit first-person mode and confirm orbit controls work again.

## Editable 3D model import

- [ ] Import a valid GLB into Spatial View; verify it appears in the viewport and is centered horizontally with its base on the floor.
- [ ] Use Translate, Rotate, and Scale gizmos; verify the imported model can be transformed independently of walls.
- [ ] Import a self-contained glTF with embedded/data-URI resources.
- [ ] Import a glTF with external texture/buffer paths; verify the UI explains that a single-file GLB or packaged resources are required.
- [ ] Import a malformed model; verify a readable error is shown and the existing building remains usable.
- [ ] Reload the page and verify the saved model file and translate/rotate/scale transform are restored from browser IndexedDB.
- [ ] Use Remove model and reload; verify the previously saved model does not return.
- [ ] Simulate IndexedDB unavailable/quota failure; verify the UI reports that local persistence failed rather than claiming it was saved.
- [ ] Confirm the UI/documentation explains that this storage is local to the browser/device and is not synced to project save/load, server, sharing, or versions.

## Upload validation

- [ ] Upload a valid GLB and confirm it is accepted as a source asset.
- [ ] Upload valid GLTF JSON and confirm it is accepted.
- [ ] Upload a valid IFC/DXF/OBJ/STL/DWG file and confirm the API stores it without claiming conversion completed.
- [ ] Rename a PNG to .glb (and vice versa); confirm signature mismatch is rejected.
- [ ] Upload malformed GLB/GLTF and an unsupported extension; confirm useful 4xx errors.
- [ ] Upload a file larger than 25 MB; confirm it is rejected and not stored.
- [ ] Verify storage keys are generated by the server and never use unsanitized path segments.

## AR device checks (supported device + HTTPS)

- [ ] Confirm the browser reports immersive AR support before enabling the session.
- [ ] Enter AR and verify the camera view follows the device without automatic software leveling.
- [ ] Record whether the model is anchored, its measured scale, floor contact, yaw, and drift over 60 seconds.
- [ ] End and re-enter the session; record whether placement resets or persists.
- [ ] Verify unsupported browsers get a clear fallback instead of a false success state.

## Current known limitations

- The current AR model placement is not yet based on a full hit-test/anchor workflow. Do not use this build as proof of reliable real-world alignment.
- First-person movement is an initial controller; swept collision, wall sliding at corners, door/window openings, stairs, and multi-floor physics are still roadmap work.
- Accepted CAD/BIM uploads are source assets only until a corresponding importer/converter reports successful conversion.
